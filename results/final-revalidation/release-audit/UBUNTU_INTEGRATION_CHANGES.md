# Native Evidence Projection Changes

This document records release-only normalization performed while integrating
the Ubuntu native evidence into the anonymous review artifact. These operations
changed paths, labels, validation logic, or packaging. They did not change any
verdict, denominator, timing measurement, unsafe outcome, distance, margin, or
historical adjudication.

| Incoming material or issue | Reviewer-facing treatment | Scientific effect |
|---|---|---|

| `final-build/runners/` | Not published because the internal wrappers contain private identity cascades, path-bound assumptions, and an unvalidated public rewrite | The package does not advertise turnkey native campaign execution; accepted results remain supported by fixed-slot records and the public recount |

## Naming decisions

Incoming labels were not copied mechanically. The public package uses:

- `VERIFIED_COMPLETE_FIXED_DENOMINATOR_REFERENCE_EVIDENCE` for Table III;
- `VERIFIED_15_OF_15_SCHEDULED_IDENTITIES__2_CONTROLLED_AND_15_NATIVE_NEGATIVES_BLOCKED` for C115;
- `ACCEPTED_FINITE_MODEL_RELATIVE_DENSE_REFERENCE` plus `PASS_20_OF_20_CHUNKS` for the dense reference and public aggregate recount;
- `PASS_ZERO_SEND_OFFLINE_ONLY` for the accepted final offline path; and
- `3_PASS__2_COVERAGE_UNKNOWN` for historical collision evidence.

These labels state completed results directly. They also preserve the three
boundaries that change interpretation: the full campaign wrappers are not
distributed, individual dense rows are compacted, and the historical collision
per-slot verdict/release/send join was not retained.

## Deliberately excluded identities

Private source-tree roots, private runner and one-shot-binary hashes, omitted
raw-result hashes, path-bearing build identities, system-library hashes,
personal paths, Git identities, archive names, media identities, and machine
serial/network identifiers are not carried into the reviewer projection.

The complete original Ubuntu return remains a private source record and is not
part of this repository.
