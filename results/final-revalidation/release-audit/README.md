# Release Audit

These files document how the compact double-anonymous package was prepared.
They are kept below the result tree so the repository root remains focused on
the paper and reproduction workflow.

- `PRIVACY_SCAN.json` records the final automated anonymity and file-hygiene
  scan.
- `PROVENANCE_PRIVACY_REDACTIONS.json` identifies the narrow release-only
  provenance substitutions without publishing the removed private values.
- `RELEASE_SELECTION_POLICY.md` states what is included, omitted, and never
  selectively hidden.
- `UBUNTU_INTEGRATION_CHANGES.md` records the selection and normalization of
  the native evidence.

These packaging operations do not change verdicts, denominators, timings,
distances, margins, or historical adjudications.
