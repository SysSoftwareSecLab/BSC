# Results

This section has two entry points:

- `CLAIM_EVIDENCE_INDEX.md` maps each paper-facing claim to its released
  evidence and states the applicable interpretation boundary.
- `final-revalidation/` contains the accepted portable and native records,
  generated-cohort results, reviewer recount tools, and release-audit records.

Start with the claim index when reviewing a paper statement. Use
`final-revalidation/README.md` for the evidence layout and `REPRODUCE.md` at the
repository root for the supported verification commands.
