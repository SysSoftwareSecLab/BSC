# External-25 LLM authoring slice

This directory retains all 12 natural-LLM attempts assigned during External-25 construction, including outputs later excluded by admission or duplication rules. `generation-records.jsonl` exposes the disposition of every attempt. External-25 also contains independently authored human programs; those sources belong under `datasets/`.

The model selector was `gpt-5.6-sol`, reasoning effort was `high`, and the recorded client was `codex-cli 0.148.0-alpha.9`. The full construction funnel was 36 assigned sources, 29 mechanically admitted sources, and 25 oracle-valid scored cases. This is repair-era benchmark evidence, not an untouched population sample. Private amendment/transfer notes were not copied. Transport transcripts, task/thread identifiers, network tracing values, complete stderr, repository history, and workstation paths were removed.
