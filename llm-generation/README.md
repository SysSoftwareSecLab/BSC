# LLM generation evidence

This is the minimum public slice needed to audit the paper's program-generation claims. It contains the actual scientific inputs, every assigned output attempt, compact execution metadata, and each attempt's later admission/eligibility disposition. It does not contain private conversations, task histories, network tracing identifiers, full stderr, local paths, account state, or unrelated prompts.

The four directories are distinct cohorts: External-40, External-25, the later 36-output no-repair multi-model cohort, and the 24-program controlled extension. `no-repair` means that generated source was not edited before admission; it does not mean that the verifier, oracle, or benchmark design was untouched by later corrections.
